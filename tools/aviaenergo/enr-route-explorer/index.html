Required before real flight planning

Verify the current AIP and applicable AIRAC amendments and supplements.
Review NOTAM and any temporary airport, runway or airspace restrictions.
Select verified runway-specific SID / STAR and valid airport-to-airway transitions.
Verify ATS route direction, permitted flight levels, RNP/RNAV equipment and airspace restrictions.
Check aircraft performance, fuel, weather, alternate, flight plan filing rules and ATC requirements.
Have a qualified dispatcher/flight operations specialist approve the actual plan.

Where the route comes from

ENR 3.1: published ATS route designators, legs, distances, headings, levels and usage remarks.

ENR 4.4: 5-letter points and published coordinates. ENR 4.1: radio navigation aids.

AD 2.2: airport reference point positions, used only as visual start/end markers.

AD 2.22 / AD 2.24: airport-specific procedures and charts, which must be matched separately.

ENR 1.10: Egyptian flight planning rules, including adherence to the published ATS route network unless permission is obtained.

Data boundary: This demo only draws the shortest distance through the network in the uploaded Egyptian AIP AMDT 03/26. It does not establish navigational validity or current route availability.
Cross-check: 178 significant point coordinates in the network matched ENR 4.4. Remaining names include navigation aids and other point types requiring their own source checks.
