Airline & Employer Architecture

A recruitment operating model that connects employer profiles, roles, requirement sets, campaigns, candidate applications, matching, shortlists, interviews and final hiring outcomes.

EMPLOYER → ROLE → REQUIREMENTS → CAMPAIGN → MATCH → SHORTLIST → INTERVIEW → OUTCOME
Recruitment flow: Employer → Job Role → Requirement Set → Recruitment Campaign → Candidate Application → Match Evaluation → Shortlist → Interview → Hiring Outcome
Traceability: Candidate stays canonical; each campaign application and evaluation is stored as a separate recruitment case/output.
